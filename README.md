# ארבעה רבעים

אפליקציית מטריצת אייזנהאואר בעברית, מוכנה לפרסום ב־GitHub Pages.

## תכונות
- ארבעה רבעים; הוספה, עריכה, מחיקה והעברה.
- גרירה בין רבעים במחשב ובמגע בטלפון; אפשר להעביר גם עם כפתור "העברה".
- שמירה אוטומטית ב־localStorage במכשיר הנוכחי בלבד.
- ייצוא וייבוא גיבוי JSON.
- PWA שניתן להוסיף למסך הבית; מטמון בסיסי לעבודה ללא חיבור אחרי ביקור ראשון.

## פרסום ב־GitHub Pages
1. יוצרים מאגר חדש ב־GitHub, למשל `arbaa-revaim`, ומגדירים אותו כ־Public.
2. מעלים **את הקבצים שבתיקייה זו** לשורש המאגר (לא את תיקיית האב).
3. ב־Settings → Pages → Build and deployment בוחרים `Deploy from a branch`, את `main`, ואת תיקיית `/(root)` ושומרים.
4. פותחים את כתובת האתר שתופיע ב־Pages (בדרך כלל `https://USERNAME.github.io/arbaa-revaim/`).
5. באייפון: פותחים ב־Safari → שיתוף → ״הוסף למסך הבית״.

**פרטיות:** כל המידע נשמר בדפדפן בלבד, ולא מסתנכרן בין מכשירים. מחיקת נתוני האתר יכולה למחוק את המשימות; מומלץ לייצא גיבוי מדי פעם.
